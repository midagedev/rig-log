# bloomery working documents

These are the maintainers' working documents for [bloomery](https://github.com/midagedev/bloomery), moved here from its `docs/` on 2026-10-11 at bloomery commit `61039d6e`: the plan and its cost models (`plan.md`), the open-work tracker (`plan-triage.md`), the closed-work ledger (`plan-ledger.md`), the machine and toolchain facts (`facts.md`), the dated plans and reviews, the research and design reports (`research/`) and the upstream pull-request drafts (`upstream/`). The paths below `docs/bloomery/` are the old paths below bloomery's `docs/`, so a reference inside a document to `docs/plan.md` or `docs/research/x.md` means `docs/bloomery/plan.md` or `docs/bloomery/research/x.md` here. Each document is true as of its date, mostly in Korean, and many were superseded later. What stayed in bloomery is the reference documentation (`docs/BUILD.md`, `serving.md`, `models.md`, ...), the designs that its code comments cite (`docs/research/modelspec-design.md`, `quant-decode-efficiency.md` and a few more) with the `docs/research/v41-placement/` scripts that read each other by relative path, the prediction cards (`docs/cards/`) and the toolchain-defect ledger (`docs/upstream/nvlabs-ledger.md`).

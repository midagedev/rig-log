# #678 tokenizer: support Flint and authoritative GGML EOG arrays (@Burntgogi, MERGED)

Refs #632; second independent CPU-only slice after #677.

## Change
- Add a distinct pre=flint using existing ordered-split/classifier owners: numbers, CJK/Kana, then the pinned mainline effective word/punctuation/whitespace program. No alias, new regex engine, Unicode tables, NFC or prefix space.
- Read tokenizer.ggml.eog_token_ids as an authoritative nonempty, typed, bounded, sorted/deduplicated stop set while retaining GGUF attribute overrides and ordinary BPE. The private bloomery key alone still selects HF mode; simultaneous sources must agree as canonical sets.
- Select Flint strict UTF-8 decoding independently of NFC. Reproduced the previous default-path overlong-byte mismatch and above-U+10FFFF panic, then fixed both with a consumer regression. Surrogate-byte behavior remains the pinned reference behavior.
- Document split-program versus final-ID differences and stop precedence.

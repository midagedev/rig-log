# #797 metal: the open makes the rows arena, so the first prompt call costs what a later one does (@midagedev, MERGED)

A Metal process's first prompt call costs what a later one does. Part of #593.

The first prompt call of a process was 85–101 ms slower than the same call warm (M4 Pro, 873 ids). `generate_metal` measures one cold call per process, so this was in every prompt rate, and in the ~100–118 ms fixed part of a call on the contributor's M3 and M5 Ultra.

Decomposition, predicted before the run, then measured (M4 Pro, 873 ids, timers only, two runs):

| term | predicted | measured |
|---|---|---|
| (a) rows arena alloc, 15 buffers | 0.1–0.3 ms | 0.28 / 0.44 ms |
| (b) host zero of 465 MB | 20–60 ms | 29.1 / 44.4 ms |
| (c) residency commit | 4–10 ms | 16.0 / 15.2 ms |
| (d) prefill pipelines | 0.2–3 ms | 0.34 / 1.15 ms |
| (f1) checkpoint slot 0, first touch | +3–12 ms | +8.5 / +8.9 ms |
| (f2) the pass itself, cold − warm | +10–60 ms | +31.4 / +29.9 ms |
| sum | | 85.6 / 100.0 ms (measured cold − warm 85.4 / 99.5) |

(c) was the wrong term: about twice the M1 Pro figure the prediction used.

- (a), (c), (d) move to `Session::open_as`: the rows arena is made there and wired by the open's one residency commit, and the prefill pipelines are built first, so a refused build fails the open before the load. Every session now holds the arena (464,863,776 bytes on this model, cap 2048 rows; a smaller ctx caps it).
- (b) is gone. Buffers come from `newBufferWithLength`, which Metal clears to zero, and no kernel of a pass reads a cell an earlier op of that pass did not write. The arena was zeroed only at its open before, so no pass sees other bits.
- `MarkCopies { AtOpen, OnFirstMark }`: the server opens the mark copies (#792, 147,456,000 bytes) with its session; other sessions keep them lazy.
- `generate_metal` prints `open_load_s`, `open_rows_ms`, `open_residency_ms`, `open_pipelines_ms` and always `rows_arena_bytes`.
- Left open: (f1) and (f2), about 36 ms of cold − warm after this change.

Gates: `r_resident` now holds that the first pass allocates nothing on the device and adds nothing to the residency set (the open's set check covers the arena). FAIL-first, the arena opened lazily again: "FAIL (the first pass moved the device's bytes by 14532608 and the residency set from 125 buffers of 2769174528 bytes to 140 of 2783707136…)". `q_short`, `q_state` and `q_mark_cut` used "the rows arena is open" as proof a pass ran; they now read `StepStats::passes`, the same fact counted directly.

Gates (M1 Pro, fixture), each rc 0: `cargo fmt --all --check`, `check-unsafe`, `check-comments`, `just check-recipes`, `just mac-metal-lint`, `just lab-metal` (114 mutants, each red on its clause), `just lab-metal-e2e` (11 mutants, each red on its clause).

## Findings that change the implementation plan

- Real UD-Q4_K_XL: **779 tensors**, header **5,470,528 B**, payload **25,049,218,176 B**; both 49-element masks, four EOG IDs and vocabulary agree with the pinned official config. Original/GGUF templates are byte-identical.
- No correction-bias tensor. `shared_routed` currently requires one; the low-level route block already represents an absent bias. Sigmoid256/top6 needs a real instance and explicit normalization policy: current `sum+1e-20` differs from mainline's `max(sum,2^-14)`.
- NoPE currently suppresses the QK-normalization need. Flint still needs QK norm and sinks in all49 layers; there is no complete callable head128/NoPE/SWA/sink program.
- Routed quant arithmetic exists, including IQ3_S prompt GEMM and Q6_K/Q8_0 down; selected wrapper/loader/down-form integration remains. Layer42 **shared IQ4_XS** is a separate dense/shared-block gap.
- The common ring needs **1024**, not513, rows for a513-token window with512-row prompt appends. Six-slot F32 tier handoff, paged-plan/load agreement and resident-slot seat plumbing are explicit prerequisites.
- Actual tokenizer/template APIs refuse Flint pretokenizer, block `set`, and `replace` arguments. Preserve the original template; extend the common owners and reuse GLM XML tool parsing. Preserve all four EOG IDs.
- File23.334GiB is below24GiB: derive device fit from actual packing/KV/scratch/reserves, not file size alone. GGUF `other/flint-preview` versus official Apache-2.0 remains an explicit provenance/redistribution condition.

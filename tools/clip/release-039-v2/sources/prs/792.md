# #792 metal: message marks kept inside one prompt call (prefill_marked) (@midagedev, MERGED)

One Metal prompt call per request, with points at the message starts inside it. Part of #593.

The server cuts a prompt call at the first and the last message start, so a later request can be cut back there and keep the recurrent state. The Metal engine asked for every cut, so chat turn 2 ran as three calls (5, 16 and 4 ids), each paying a pass or steps and a checkpoint. Its doc said such a cut is bit-neutral; since the batched pass it is not (a part of up to 8 ids steps, a longer one passes).

- `Engine::prefill_marked(ids, media, marks)` (serve): the server runs every part of a prompt call through it, with the marks that fall in that part. The default is `prefill` / `prefill_media` and reads no mark, so every other engine runs as before, byte for byte. `SwapEngine` forwards text calls.
- `Target::prompt_marked` (runtime): the default runs one `prompt` a part, cut at each mark.
- The Metal engine cuts nowhere and hands the marks to `Session`'s `prompt_marked`. A mark inside a pass is a copy the pass leaves after the row before it (`StateOut::after_rows`, up to two a pass), taken as a point once the pass settles. A mark inside a run of steps ends that run. A third mark ends the pass there.
- Delta kernels: `gdn_rows_snap` writes the lane's registers after each named row into a copy; `gdn_ring_snap` writes the ring a chunk ending at that row would leave, before the ring commit. The pass's own outputs do not move. The copy buffers open on the first pass that takes one.

Gates:
- kernels `delta_rows_snap`: each copy equals, bit for bit, the lane and ring of a launch over rows 0..=r, and the copies move no output. FAIL-first: a copy one row late, a ring not copied.
- e2e `q_mark`: copies move none of the pass's bits (pick, logits row, every store); the copy after the last row, cut back to, is the pass's end state; a copy's ring slots before the pass are the ring the pass found; a copy is the same beside any other. FAIL-first: a copy one row late, a ring not copied, a point taken from the live ring.
- e2e `q_mark_cut`: 1024 ids marked at 700 and 1017, cut back to each and continued twice: the same bits both times, and four teacher-forced tokens within `q_free`'s band of the stepped run.
- e2e `k_keep`: `prefill_splits` cuts nowhere and `prefill_marked` keeps each mark.
- serve: the genloop hands each part its marks (default engine: the same calls as before); an engine that keeps marks gets one call with them.

- Register Flint in both architecture enums and the shared reader/registry; no fixture, draft or Program row.
- Reuse common metadata helpers, stem groups, classification, tensor-set and dimension checks. Preserve independent SWA/RoPE masks, explicit head128/Q4096 geometry, two dense lead layers, sigmoid MoE256/top6, optional selection-only bias, and one ungated shared1024 MLP (shared_count2 is a width ratio, not two modules).
- Fix the common needs walk so NoPE with qk_norm still emits its normalization need. Leave program_of(Flint)=None and the unsupported numerical/site needs visible.

- Add synthetic malformed-header regressions, the hash-pinned header gate, recipe/class/family/path/registry bookkeeping, and update the existing design document to distinguish its historical gap snapshot from current reader-only support.
- Generic Router.norm records requested normalization; this PR does not implement Flint’s denominator floor or activated-value scaling. No execution admission can depend on that flag alone.
